# A11Y.md — Aksesibilitas (Target WCAG 2.2 AA)

> **Status:** 🟢 **ditingkatkan (M15)** — tooling a11y (lint + axe), reduced-motion, UI galat bertema. Uji perangkat nyata/screen-reader masih utang.
> **Target:** **WCAG 2.2 Level AA**.
> **Sifat:** dokumen hidup — perbarui saat audit/komponen baru.

---

## 1. Prinsip

MathBank dipakai guru/admin jangka panjang (sesi panjang, teks & rumus padat). Aksesibilitas = kualitas, bukan beban. Empat pilar **POUR**: Perceivable, Operable, Understandable, Robust.

## 3. Checklist WCAG 2.2 AA (yang harus dijaga)

**Persepsi (Perceivable)**
- [x] Kontras teks ≥ 4.5:1; teks besar ≥ 3:1
- [x] Kontras komponen/grafis ≥ 3:1
- [ ] Semua gambar punya `alt` bermakna (audit)
- [ ] Rumus/rumus gambar punya teks alternatif (KaTeX → MathML/aria)

**Operabilitas (Operable)**
- [x] Semua fungsi via keyboard
- [x] Skip link + fokus terlihat
- [ ] Target sentuh ≥ 24×24 px (WCAG 2.2 baru — audit mobile)
- [ ] Tak ada perangkap fokus (audit dialog/modal)
- [x] `prefers-reduced-motion` dihormati (`globals.css`, M15)

**Keterpahaman (Understandable)**
- [x] Bahasa dokumen = `id` (Indonesia)
- [x] Pesan error jelas & spesifik (kode + pesan; UI galat bertema M15)
- [x] Label form terhubung input (M15 — `htmlFor`/`id`; dijaga lint jsx-a11y)

**Kokoh (Robust)**
- [x] HTML semantik + landmark
- [ ] Diuji dengan screen reader (NVDA/VoiceOver) — belum

## 5. Aturan Pengembangan

1. **Selalu pakai komponen shadcn resmi** (punya aksesibilitas Base UI). Jangan bikin kontrol mentah.
2. **Setiap kontrol ikon** wajib `aria-label`.
3. **Jangan sampaikan info lewat warna saja** — tambah teks/ikon.
4. **Uji Tab + Enter + Esc** sebelum menandai UI selesai.
5. **Rumus:** pastikan KaTeX punya jalur teks alternatif.
